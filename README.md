# 여백 · 일상에 쉼표를 그리는 기록

지애와 인웅, 두 사람만의 나들이·여행 기록 앨범.

- 주소: https://imapstudio-jiae.github.io/jia/
- 잠금 비밀번호(6자리)는 `index.html` 안에 있습니다. 이 저장소는 공개 저장소이므로 소스를 보면 비밀번호를 알 수 있는 가벼운 잠금입니다.
- `index.html` 하나로 동작하는 정적 웹앱입니다. 빌드 과정이 없습니다.

## 구성

- **잠금**: 6자리 비밀번호. 한 번 풀면 그 브라우저 세션 동안 유지되고, 오른쪽 위 `잠금` 버튼으로 즉시 다시 잠급니다. 잠금이 풀리기 전에는 데이터를 불러오지 않습니다.
- **저장**: Supabase `studio_schedule` 테이블의 `trip_album_index_v1`(목록)과 `trip_<날짜>_<id>`(개별 기록) 키를 사용합니다. 시간표 앱의 `2026-*`, `fees_*`, `student_histories` 키는 건드리지 않습니다.
- **사진**: 브라우저에서 긴 변 1,500px·JPEG 품질 0.78로 줄여 담고, 기록 한 건당 5MB까지 저장합니다. 목록용 썸네일은 300px입니다.
- **기능**: 새 기록, 사진 크게 보기(좌우 넘김·스와이프·저장), 기록 수정, 삭제.

## 참고

비밀번호 잠금은 화면을 가리는 장치입니다. 사진과 글은 Supabase 테이블에 그대로 저장되므로, 주소와 비밀번호를 아는 사람은 볼 수 있습니다.

## 아이콘·홈 화면 앱

- 아이콘: `icon-512.png`, `icon-192.png`, `icon-512-maskable.png`, `apple-touch-icon.png`, `favicon.png`, `favicon-32.png` (1024 원본에서 축소)
- 아이콘 바탕: `#FDD835`(구글 옐로 `#FBBC04`보다 한 단계 밝은 노랑) 위에 원래 나뭇잎 마크(`#2E3A43`)
- `manifest.json`: 이름 `여백`, `display: standalone`, 시작 주소 `./`
- `sw.js`: 캐시를 쓰지 않는 최소 서비스 워커. 홈 화면 '앱 설치'가 가능하도록 등록만 합니다.
- 안드로이드 크롬에서 주소를 열고 메뉴 → `홈 화면에 추가`(또는 `앱 설치`).
